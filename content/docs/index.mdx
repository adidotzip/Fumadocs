# AntamScript

**ForgeScript, but B I G.**

AntamScript is an early-stage TypeScript project from NationDex. The current repository is intentionally small, so these docs describe the implementation that exists today and avoid presenting planned features as finished features.

## Current status

The current runtime contains a single TypeScript entry point that logs a message to the console.

```text
AntamScript is B I G
```

The project uses Bun, TypeScript, Biome, and `discord.js`. Discord functionality is not implemented in the current source tree yet.

## Get started

Install [Bun](https://bun.sh/) 1.4.2 or newer, then clone the repository:

```bash
git clone https://github.com/nationdex/antamscript.git
cd antamscript
bun install
```

Run the project:

```bash
bun run dev
```
