## Package configuration

### `package.json`

The package manifest identifies the package as `@nationdex/antamscript`, currently at version `1.0.0`, and marks it as private.

It defines Bun-based scripts for development, building, starting, formatting, checks, and type checking.

### `tsconfig.json`

TypeScript is configured with:

- ESNext target
- ESNext modules
- Bundler module resolution
- Strict type checking
- Bun types
- `skipLibCheck`
- No emitted files from the TypeScript checker

### `biome.json`

Biome provides the repository's formatting and code-quality tooling.

### `bun.lock`

The Bun lockfile records the dependency resolution used by the project.
