# Installation

AntamScript currently uses **Bun** as its JavaScript runtime and package manager.

## Requirements

- Git
- Bun **1.4.2 or newer**

Check your Bun version with:

```bash
bun --version
```

## Clone the repository

```bash
git clone https://github.com/nationdex/antamscript.git
cd antamscript
```

## Install dependencies

```bash
bun install
```

The project currently has one runtime dependency:

```text
discord.js
```

## Run AntamScript

Start the project in development mode:

```bash
bun run dev
```

Or run the entry point normally:

```bash
bun run start
```

You should currently see:

```text
AntamScript is B I G
```
